# SayatSays

[Русский](README.md) · [English](README.en.md) · **Қазақша**

Телефонға арналған аралықпен қайталау карточкалары: қазақ тілі, ағылшын тілі, мектеп пәндері — есте сақтағыңыз келетін кез келген нәрсе.

### ▶ [Қосымшаны ашу](https://dwlqx.github.io/SayatSays/) — https://dwlqx.github.io/SayatSays/

Тегін, тіркелусіз және жарнамасыз. Интернетсіз жұмыс істейді. Барлық деректер тек сіздің құрылғыңызда сақталады.

**Қосымшаның тілі — орыс тілі.** Төменде батырмалардың атауы орысша, жақшада — аудармасы.

## Мүмкіндіктері

- Әр карточканы қашан қайталау керегін өзі шешеді (FSRS алгоритмі): қиындары жиірек, оңайлары сирегірек шығады.
- Бастауға дайын жинақтар: қазақ тілі (лексика, емтихан тапсырмаларының тұжырымдары және грамматикалық терминдер)
  және NUET-ке арналған ағылшын тілі (логика мен математика). Керегі жоғын өшіре аласыз.
- Өз жинақтарыңыз — қолмен немесе Claude көмегімен: қосымшада чатқа қоя салатын нұсқаулық бар.
- Карточканың төрт түрі: орысша → қазақша, қазақша → орысша, сөйлемдегі бос орынға ағылшын сөзі, сұрақ пен жауап.
- Күндер сериясы (мұздату мүмкіндігімен), статистика және екі аптаға болжам, белгішедегі карточкалар саны.
- Безендірудің 13 тақырыбы — ашық және қараңғы.
- Барлық деректің сақтық көшірмесі бір файлға.

## Қалай орнатуға болады

**iPhone және iPad**
1. Сілтемені **Safari**-де ашыңыз.
2. «Поделиться» / Share (жебесі бар шаршы; жаңа iOS-те «•••» мәзірінде болуы мүмкін) →
   «На экран Домой» / Add to Home Screen → «Добавить» / Add.
3. SayatSays-ты басты экрандағы белгішеден ашыңыз: толық экранда және интернетсіз жұмыс істейді.

Safari мен басты экрандағы қосымшаның деректері бөлек, сондықтан қосымшада оқыңыз.

**Android** — сілтемені Chrome-да ашыңыз → «⋮» мәзірі → «Установить приложение» / Install app.

**Компьютер** — сілтемені жай ашыңыз. Chrome мен Edge-те оны қосымша ретінде орнатуға болады: мекенжай жолындағы орнату белгісі.

## Қалай пайдалану керек

1. «Повторить всё» (бәрін қайталау) — бүгінгі барлық карточкалар бойынша сабақ. Немесе жинақты ашып, «Учить» (оқу) батырмасын басыңыз.
2. Жауапты есіңізге түсіріп, карточканы аударыңыз да, шынын айтыңыз: «Не знал» (білмедім) немесе «Знал» (білдім).
   Сырғытуға да болады: солға — білмедім, оңға — білдім.
3. Күн сайын аздап оқыңыз. Жаңа карточкалар өздігінен қосылады: әдепкі бойынша әр жинақтан күніне 15-ке дейін.

Баптауларда («Настройки», тісті доңғалақ) — безендіру тақырыптары, күндік мақсат, екі батырманың орнына төрт батырма
(«Трудно» — қиын, «Легко» — оңай) және белгішедегі сан. Басты экрандағы бағандар белгішесі — статистика.

## Claude көмегімен өз карточкаларыңыз

1. Басты экранда: «Добавить» (қосу) → «Скопировать инструкцию для Claude» (Claude үшін нұсқаулықты көшіру).
2. Оны Claude чатына ([claude.ai](https://claude.ai)) қойып, не керегін жазыңыз, мысалы: «"Қала" тақырыбына 30 карточка».
3. Claude жауабындағы код блогының «Копировать» / Copy батырмасын басыңыз.
4. Қосымшада «Вставить ответ Claude» (Claude жауабын қою) батырмасын басып, не қосылатынын тексеріңіз де, «Добавить» батырмасын басыңыз.

Жауапта қате болса, қосымша не дұрыс емес екенін көрсетеді — сол қатені көшіріп, Claude-қа қайта жіберіңіз.
Карточкаларды қолмен де қосуға болады: жинақты ашыңыз → «Добавить».

## Деректерім қайда?

Тек сіздің құрылғыңызда, браузердің ішінде. Оларды ешкім көрмейді және еш жаққа жіберілмейді. Сондықтан:
- қосымшаны басты экраннан өшірсеңіз немесе сайт деректерін тазаласаңыз, деректер жоғалады;
- анда-санда сақтық көшірме жасап тұрыңыз: «Настройки» → «Данные» → «Сделать резервную копию», файлды «Файлы»
  қолданбасына немесе бұлтқа сақтаңыз;
- жаңа телефонда: «Настройки» → «Данные» → «Восстановить из копии» (көшірмеден қалпына келтіру).

## Сұрақтар

**Еске салғыштар бар ма?** Бүгінгі карточкалар саны белгішеде көрінеді — иә: «Настройки» → «Число на иконке».
Кесте бойынша хабарландыруларды GitHub жібереді, сондықтан оларды тек жобаның өз көшірмесінде баптауға болады
([әзірлеушілерге арналған нұсқаулық](docs/DEVELOPMENT.md#напоминания), орыс тілінде).

**Қанша тұрады?** Тегін.
