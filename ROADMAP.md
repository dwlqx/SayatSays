## Задача 1. Отдельное приложение с локальным хранилищем

**Цель:** «Запомни» работает как обычный сайт, без claude.ai, и хранит всё в IndexedDB.

1. Разнеси `legacy/zapomni-artifact.html` на файлы по структуре из `CLAUDE.md`. Сам `legacy/` не трогай.
2. Убери всё, что связано с `window.claude` (`connect`, `db`, `user`, `canEdit`, синхронизацию, очередь записи `W`,
   тосты про облако). Редактирование колод и карточек доступно всегда.
3. `js/db.js`: IndexedDB-хранилища `decks`, `cardState`, `reviewLog`, `settings`, `stats`. Тонкая обёртка без библиотек.
   Вызови `navigator.storage.persist()` при первом запуске.
4. Первый запуск (база пустая): загрузи `./data/decks.json` и `./data/progress-sm2.json` и положи в базу.
   Прогресс пока в старом формате SM-2, алгоритм пока тоже старый (FSRS — задача 3). Серия дней должна сохраниться.
5. Настройки → раздел «Данные»:
   - «Сделать резервную копию»: один JSON со всем (колоды, состояния, журнал, настройки, статистика).
     На iPhone через `navigator.share({files})`, иначе скачивание файла.
   - «Восстановить из копии»: выбор файла, предупреждение, что текущие данные заменятся.
   - «Импортировать колоды»: файл в формате `decks.json`; колоды с тем же `id` дополняются новыми карточками, прогресс не теряется.
   - Строка «Последняя копия: N дней назад».
6. Шрифты — локально в `fonts/`.
7. Тесты в `tests/`: импорт исходных данных (13 колод, 242 карточки, 80 карточек с прогрессом), круг «копия → восстановление» без потерь.

**Готово, когда:** приложение, запущенное через локальный сервер (`python3 -m http.server`, по `file://` модули и JSON
не загрузятся), показывает все колоды и серию; учёба работает; после перезагрузки прогресс на месте.
Сделай скриншот главного экрана и экрана карточки и покажи Роме.

## Задача 2. PWA, иконка и публикация

**Цель:** приложение ставится на экран «Домой», открывается без браузерной рамки и работает офлайн.

1. Иконка: Рома выбрал вариант C «Петля» — `icons/options/c-petlya/`. Скопируй в `icons/`: `apple-touch-icon.png` (180),
   `icon-192.png`, `icon-512.png`, `icon-1024.png`. PNG без прозрачности (iOS заливает прозрачное чёрным).
2. `manifest.webmanifest`: `name`/`short_name` = «SayatSays», `display: standalone`, `start_url: "./"`, `scope: "./"`,
   цвета темы и фона из палитры приложения, иконки 192 и 512 с `purpose: "any"` и отдельно `"maskable"`.
3. `index.html`: ссылка на манифест, `apple-touch-icon`, `apple-mobile-web-app-title`, `theme-color` для светлой и тёмной темы.
4. `sw.js`: кэширует всё приложение (HTML, CSS, JS, vendor, шрифты, иконки, data). Стратегия: сначала кэш, потом сеть.
   Версия кэша — константа, старые кэши удаляются при активации.
5. Обновления: когда установлен новый service worker, показывай плашку «Доступно обновление» с кнопкой «Обновить».
6. Если приложение открыто в Safari, а не с экрана «Домой», — один раз покажи подсказку, как его установить,
   и предупреди, что у Safari и у приложения на экране разные данные.
7. Добавь в `README.md` ссылку на сайт и инструкцию по установке на iPhone.

**После merge Рома включает Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`.

**Готово, когда:** на iPhone с экрана «Домой» приложение открывается без адресной строки, с иконкой, и работает в авиарежиме.

## Задача 3. FSRS вместо SM-2

**Цель:** расписание считает FSRS-6 через `ts-fsrs`.

1. Положи в `vendor/` ESM-сборку `ts-fsrs` из npm (версия и лицензия в комментарии в начале файла).
2. `js/scheduler.js`: обёртка над `fsrs()`. Параметры по умолчанию, `request_retention` = 0.9, fuzz включён,
   короткие шаги: изучение `1m, 10m`, переучивание `10m`, `maximum_interval` = 365.
   «Не знал» → `Rating.Again`, «Знал» → `Rating.Good`.
3. Под кнопками показывай, когда карточка вернётся (например «10 мин» / «4 дн»), через `scheduler.repeat()`.
4. Миграция из SM-2 (`js/migrate.js`, один раз, с резервной копией перед ней):
   - `s=0` → новая карточка (`createEmptyCard`).
   - `s=2` (на повторении) → состояние Review: stability ≈ `iv` дней, difficulty ≈ 5 (+1 за каждый провал `l`, в пределах 1–10),
     `last_review` = `t`, `due` = день `d` (граница дня — 4:00 по местному времени, см. `dayIndex` в артефакте).
   - `s=1` (изучается) → состояние Learning, `due` = сейчас.
   - Если в `ts-fsrs` есть готовый способ задать состояние памяти из таких данных — используй его вместо ручного.
5. Каждый ответ пишется в `reviewLog`: id карточки, оценка, время, состояние до ответа (то, что возвращает `ts-fsrs` в `log`).
6. «Выучено» = карточка в состоянии Review со stability ≥ 21 дня. Обнови подписи в интерфейсе и в настройках.
7. Настройки: «Целевая запоминаемость» 80–95 % (по умолчанию 90) с пояснением: выше — больше повторений.
8. Лимит новых карточек в день, отмена ответа, серия дней с двумя заморозками в неделю — сохранить.
9. Тесты: миграция 80 карточек без потерь; ответ «Знал» на новую карточку переводит её в Learning; отмена возвращает состояние.

**Готово, когда:** после обновления на iPhone прогресс на месте, под кнопками видны интервалы, журнал ответов растёт.

## Задача 4. Напоминания о повторении

**Цель:** раз в день приходит уведомление «N карточек ждут повторения», на иконке — бейдж с числом.
Своего сервера нет: push отправляет GitHub Actions по расписанию.

1. VAPID-ключи: сгенерируй (`npx web-push generate-vapid-keys`). Публичный — в `js/config.js`.
   Приватный НЕ коммить: выведи его Роме один раз и попроси добавить в GitHub Secrets как `VAPID_PRIVATE_KEY`
   (и публичный как `VAPID_PUBLIC_KEY`).
2. Настройки → «Напоминания»: кнопка «Включить». Показывать только в установленном приложении (`display-mode: standalone`),
   в Safari — подсказку установить. По нажатию: `Notification.requestPermission()`, затем
   `pushManager.subscribe({userVisibleOnly: true, applicationServerKey})`.
3. После подписки покажи JSON подписки и кнопку «Скопировать» с инструкцией: GitHub → Settings → Secrets and variables →
   Actions → New secret `PUSH_SUBSCRIPTION`.
4. `sw.js`, событие `push`: прочитай из IndexedDB, сколько карточек к повторению сегодня, и **всегда** покажи уведомление
   (iOS отзывает разрешение за push без уведомления). Если 0 — спокойный текст без давления.
   Поставь бейдж `setAppBadge(n)`, если поддерживается. По нажатию на уведомление — открыть приложение.
   Приложение обновляет бейдж при открытии и после занятия.
5. `.github/workflows/reminder.yml`: `schedule` (cron в UTC; 19:00 по Алматы = `0 14 * * *`) + `workflow_dispatch` для ручной проверки.
   Скрипт `tools/send-push.mjs` на пакете `web-push` (версия зафиксирована) отправляет push по `PUSH_SUBSCRIPTION`.
   VAPID subject — `https://dwlqx.github.io/SayatSays/`. Если ответ 404/410 — завершить с понятной ошибкой «подписка устарела, подпишись заново».
6. В `README.md`: как поменять время, как проверить кнопкой Run workflow, и что GitHub отключает расписание
   в публичном репозитории после 60 дней без активности (как включить обратно).

**Готово, когда:** ручной запуск workflow присылает на iPhone уведомление с правильным числом карточек.
