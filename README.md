# SayatSays

Приложение с карточками для интервального повторения: казахский, английский, школьные предметы.
Работает на iPhone как приложение с экрана «Домой», офлайн, с напоминаниями. Расписание — FSRS.

- `CLAUDE.md` — контекст и правила проекта (его автоматически читает Claude Code)
- `ROADMAP.md` — задачи по порядку
- `index.html`, `css/`, `js/`, `fonts/`, `icons/`, `manifest.webmanifest`, `sw.js` — само приложение
- `tests/` — проверки логики (запускаются в Node)
- `tools/`, `.github/workflows/reminder.yml` — отправка напоминаний (см. «Напоминания»)
- `data/` — колоды (242 карточки) и прогресс, перенесённые из артефакта «Запомни»
- `icons/options/` — варианты иконки (выбран C «Петля»)
- `legacy/` — исходный артефакт, из которого всё выросло

**Сайт:** https://dwlqx.github.io/SayatSays/

## Установка на iPhone

1. Открой https://dwlqx.github.io/SayatSays/ в **Safari** (в других браузерах на iPhone пункта может не быть).
2. Нажми «Поделиться» — квадрат со стрелкой вверх. В новых iOS он может быть в меню «•••».
3. Выбери «На экран Домой» → «Добавить».
4. Открывай SayatSays иконкой с экрана «Домой»: на весь экран, без адресной строки, работает без интернета.

У Safari и у приложения на экране «Домой» **разные данные**. Если уже занимался в Safari — сделай там
резервную копию (Настройки → Данные) и восстанови её в приложении.

## Как выпустить новую версию

1. Подними номер на 1 в двух местах: `VERSION` в `sw.js` и в `js/version.js` (тест проверит, что они равны).
2. Если добавил новый файл приложения — допиши его в список `FILES` в `sw.js` (тест подскажет, какой забыт).
3. Смёрдж в `main` — через минуту-две GitHub Pages обновит сайт.
4. На iPhone при следующем открытии появится плашка «Доступно обновление» → «Обновить».
   Номер версии виден внизу настроек.

Если версию не поднять, iPhone так и будет показывать старую версию из кэша.

## Как устроен код

| Файл | Что делает |
|---|---|
| `js/app.js` | интерфейс: экраны, кнопки, настройки |
| `js/db.js` | хранилище на устройстве (IndexedDB) |
| `js/scheduler.js` | когда показывать карточку снова: обёртка над FSRS-6 (`vendor/ts-fsrs.mjs`) |
| `js/study.js` | занятие: какая карточка следующая, ответ, отмена ответа |
| `js/streak.js` | учебные дни (день начинается в 4:00) и серия с заморозками |
| `js/decks.js` | дерево колод, счётчики, очередь занятия, импорт колод из файла |
| `js/backup.js` | формат резервной копии |
| `js/migrate.js` | перенос `data/*.json` в базу при первом запуске и переход с SM-2 на FSRS |
| `js/push.js` | напоминания в приложении: разрешение, подписка на push, число на иконке |
| `js/config.js` | публичный ключ для push (приватный — только в GitHub Secrets) |
| `js/version.js` | номер версии (показывается внизу настроек) |
| `vendor/ts-fsrs.mjs` | библиотека FSRS (ts-fsrs 5.4.2, MIT), готовый файл из npm |
| `sw.js` | service worker: хранит приложение на устройстве для работы офлайн, скачивает обновления, показывает напоминания |
| `tools/send-push.mjs` | отправляет push-напоминание; его запускает GitHub Actions |
| `tools/make-vapid.mjs` | создаёт ключи для push: приватный — сразу в GitHub Secrets, публичный — в `js/config.js` |
| `manifest.webmanifest` | название, иконки и режим «как приложение» для экрана «Домой» |

Данные хранятся только на устройстве. Резервная копия и импорт колод — в Настройки → «Данные».

## Как считается расписание

FSRS для каждой карточки помнит **стабильность** (через сколько дней вероятность вспомнить упадёт до 90 %)
и **сложность** (1–10). После ответа он пересчитывает их и назначает следующий показ так, чтобы ты вспоминал
карточку с вероятностью, равной «целевой запоминаемости» из настроек (по умолчанию 90 %).

- Новая карточка: «Не знал» — снова через минуту, «Знал» — через 10 минут, потом — на дни.
- Забытая карточка: снова через 10 минут, потом — на дни. Не дольше года между повторениями.
- Под кнопками видно, когда карточка вернётся. «Выучено» — стабильность от 3 недель.
- Каждый ответ пишется в журнал (`reviewLog`): позже по нему можно подогнать параметры FSRS под тебя.

## Напоминания

Утром и вечером на телефон приходит уведомление «12 карточек ждут повторения», а на иконке — их число.
Своего сервера нет: push отправляет GitHub Actions по расписанию (`.github/workflows/reminder.yml`).
В push нет ни текста, ни чисел — телефон сам считает карточки по своей базе (`sw.js`), поэтому данные с телефона
никуда не уходят. На GitHub лежит только подписка — адрес телефона для push.

### Как включить (один раз)

1. На iPhone, в приложении с экрана «Домой»: Настройки → «Напоминания» → «Включить напоминания» → «Разрешить».
2. Там же «Подписка для GitHub» → «Скопировать».
3. На GitHub: репозиторий → Settings → Secrets and variables → Actions → New repository secret.
   Name: `PUSH_SUBSCRIPTION`, в Secret вставь скопированное → Add secret.
4. Проверь: Actions → «Напоминание» → Run workflow → Run workflow. Через минуту придёт уведомление.

Секрет `VAPID_PRIVATE_KEY` уже положил туда `tools/make-vapid.mjs`. Публичный ключ — в `js/config.js`.

### Как поменять время

В `.github/workflows/reminder.yml` строки `cron: 'минута час * * *'`. Время там **по UTC**: в Алматы UTC+5,
поэтому из времени Алматы вычитай 5 часов. Сейчас:

| Алматы | cron (UTC) |
|---|---|
| 7:09 | `'9 2 * * *'` |
| 18:45 | `'45 13 * * *'` |

Например, 8:30 по Алматы — `'30 3 * * *'`. Лишнее напоминание — удали его строку.
GitHub запускает по расписанию с опозданием: обычно на несколько минут, иногда до часа. В начале часа очередь
больше всего, поэтому время лучше ставить не ровно в :00.

### Если что-то не так

- **Проверить без GitHub:** в приложении «Проверить уведомление» — придёт то же уведомление, что по расписанию.
- **Workflow красный** — открой запуск в Actions, там написано, что не так. GitHub пришлёт и письмо.
  - «Подписка устарела»: в приложении «Создать новую подписку» (или «Включить напоминания»), скопируй и обнови
    секрет `PUSH_SUBSCRIPTION` (Secrets → карандаш рядом с ним). Так бывает, если удалить приложение с экрана «Домой».
  - «Сервер push не принял подпись (403)»: ключи не совпадают — см. «Сменить ключи».
- **Расписание остановилось.** В публичном репозитории GitHub выключает расписание, если **60 дней** не было
  коммитов. Включить обратно: Actions → «Напоминание» → кнопка **Enable workflow**. Любой коммит тоже сбрасывает счёт.
- **Выключить напоминания:** Actions → «Напоминание» → «•••» → Disable workflow. Или выключи уведомления SayatSays
  в настройках iPhone.
- **Сменить ключи** (если приватный ключ куда-то утёк): `node tools/make-vapid.mjs --force`, закоммить `js/config.js`,
  дождись обновления приложения на телефоне, потом «Создать новую подписку» и обнови `PUSH_SUBSCRIPTION`.

Логи Actions в публичном репозитории видны всем. Поэтому скрипт отправки никогда не печатает подписку и ключи.

## Запуск на компьютере

Двойной щелчок по `index.html` не сработает: по адресу `file://` браузер не загружает модули и JSON.
Нужен локальный сервер. В папке проекта:

```bash
python -m http.server 8000
```

Потом открой http://localhost:8000. (На Mac и Linux команда может называться `python3`.)

Service worker на localhost тоже работает, поэтому после правок может открыться старая версия из кэша.
Тогда подними версию (см. выше) или в инструментах разработчика браузера: Application → Service workers → Unregister.

## Тесты

Нужен Node.js 20 или новее. Один раз установи пакет для тестов, потом запускай проверки:

```bash
npm install
npm test
```

Пакет `fake-indexeddb` нужен только тестам: он имитирует IndexedDB в Node. `web-push` — скриптам напоминаний в `tools/`.
В само приложение ни один из них не попадает.
