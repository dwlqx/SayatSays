# SayatSays

Приложение с карточками для интервального повторения: казахский, английский, школьные предметы.
Работает на iPhone как приложение с экрана «Домой», офлайн, с напоминаниями. Расписание — FSRS.

- `CLAUDE.md` — контекст и правила проекта (его автоматически читает Claude Code)
- `ROADMAP.md` — задачи по порядку
- `data/` — колоды (242 карточки) и прогресс, перенесённые из артефакта «Запомни»
- `icons/options/` — варианты иконки
- `legacy/` — исходный артефакт, из которого всё выросло

Сайт появится по адресу https://dwlqx.github.io/SayatSays/ после задачи 2.
