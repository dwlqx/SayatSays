# SayatSays — контекст проекта для Claude Code

## Что это
Личное приложение с карточками для интервального повторения (казахский, английский, школьные предметы).
Выросло из артефакта Claude «Запомни» (`legacy/zapomni-artifact.html`). Пользователь один — владелец репозитория Рома,
он учится программировать, поэтому объясняй решения простым языком и не прячь важную логику в «магию».

## Как оно работает на телефоне
- Веб-приложение (PWA) на GitHub Pages: `https://dwlqx.github.io/SayatSays/`.
- Рома добавляет его на экран «Домой» iPhone (Safari → Поделиться → «На экран Домой»). Открывается без адресной строки.
- Данные хранятся только на телефоне, в IndexedDB. Синхронизации между устройствами НЕТ и не нужно.
- Работает офлайн (service worker кэширует всё приложение).
- Напоминания: Web Push (iOS 16.4+, только для приложения с экрана «Домой»). Отправляет их GitHub Actions по расписанию,
  своего сервера нет. Подробности — задача 4 в `ROADMAP.md`.

## Технические решения (не менять без обсуждения с Ромой)
- **Без сборщика.** Чистые HTML + CSS + ES-модули JavaScript. Никаких React/Vite/TypeScript-компиляции.
  Сторонние библиотеки кладём готовыми ESM-файлами в `vendor/` (с лицензией и номером версии в комментарии).
- **Все пути относительные** (`./app.js`, `./icons/...`): сайт живёт в подпапке `/SayatSays/`, абсолютный `/app.js` сломается.
- **Алгоритм повторения — FSRS** через библиотеку `ts-fsrs` (FSRS-6). Кнопки: «Не знал» = `Rating.Again`, «Знал» = `Rating.Good`.
  Каждый ответ пишется в журнал `reviewLog` — он нужен, чтобы позже подогнать параметры FSRS под Рому.
- **Шрифты локально** (Golos Text, Literata — лицензия OFL), без Google Fonts: иначе офлайн отвалится. Удобно взять из npm-пакетов `@fontsource/*`.
- **Логика отдельно от интерфейса.** Расписание, серия дней, миграция данных — в модулях без DOM, чтобы их можно было
  проверять тестами в Node (`node --test`).
- Интерфейс на русском. Внешний вид, цвета и поведение карточек сохраняем как в артефакте, если задача не говорит иное.

## Строгие правила
- **Репозиторий публичный.** Никаких секретов в коде и коммитах: приватный VAPID-ключ, токены, подписки на push — только в
  GitHub Secrets. Публичный VAPID-ключ можно хранить в коде. Перед коммитом проверь diff на секреты.
- Не удалять и не переписывать `data/decks.json` и `data/progress-sm2.json` — это исходные данные Ромы.
- Изменения в формате хранения данных — только с миграцией старых данных, без потерь.
- При каждом релизе поднимать версию кэша в service worker, иначе iPhone покажет старую версию.
- Одна задача из `ROADMAP.md` = одна ветка и один pull request. Сначала план, потом код.
- После изменений: прогони тесты, затем коротко напиши Роме, что проверить на iPhone.

## Данные
- `data/decks.json` — 13 колод, 242 карточки. Колода: `{id, name, type, parent, order, cards[]}`.
  Типы: `kz` (русский → казахский: `ru`, `kz`, `note?`), `kzru` (казахский → русский), `en`
  (`word`, `ipa`, `ru`, `def`, `sentences[]`, слово в предложении в `{фигурных скобках}`), `qa` (`q`, `a`).
- `data/progress-sm2.json` — прогресс из артефакта (SM-2) по 80 карточкам + статистика дней. Формат описан в поле `note`.
  Истории отдельных ответов там нет, только текущее состояние.
- Новые колоды Рома будет получать от Claude в чате JSON-файлом того же формата, что `decks.json`, и импортировать в приложении.
